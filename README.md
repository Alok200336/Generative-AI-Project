# Generative AI Project

This repository contains my hands-on work and experiments in Generative AI. It covers Large Language Models (LLMs), prompt engineering, chat models, embeddings, Hugging Face models, LangChain, and API-based AI applications.

## Technologies Used

- Python
- LangChain
- Hugging Face
- LLM APIs
- Embedding Models
- Prompt Engineering
- uv for Python environment and dependency management

## Project Structure

The repository includes examples and experiments related to:

- Chat models
- Hugging Face models
- Local LLMs
- Text embeddings
- Prompt engineering
- Generative AI workflows

## Goal

The goal of this repository is to learn, experiment with, and build practical Generative AI applications using modern LLM tools and frameworks.
